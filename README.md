[⬇ Baixar FinNote para Android](https://github.com/vicktordarosa07-source/FinNote/releases/latest/download/FinNote.apk)

App Android nativo para registro financeiro local.

## Recursos
- Gastos por categoria, renda mensal fixa e rendas extras.
- Resumo de entradas, saídas e saldo do mês.
- Ditado pt-BR com classificação por palavras-chave e revisão antes de salvar.
- Perfil local para identificar o autor dos registros.
- Atalho **Falar gasto** no menu do launcher ao manter o ícone pressionado (Android 7.1+ compatível).

## Limitações
Os dados ficam neste aparelho. Esta versão ainda não implementa autenticação nem sincronização entre aparelhos; a identificação é um nome local. O reconhecimento depende do serviço de fala habilitado no Android. Manter o ícone pressionado abre o menu de atalhos; toque em **Falar gasto** para iniciar o ditado.

## Build
Abra a pasta no Android Studio e use **Build > Build APK(s)**. O GitHub Actions também compila o APK de debug em cada push e publica o arquivo como artefato da execução. Para distribuição, configure uma assinatura de release.
